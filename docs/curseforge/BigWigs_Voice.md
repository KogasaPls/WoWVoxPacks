# BigWigs Voice: WoWVoxPacks ({Voice})

A TTS voice pack for BigWigs. It is a drop-in replacement for [BigWigs_Voice](https://www.curseforge.com/wow/addons/bigwigs_voice), speaking every callout that addon has in the Google Cloud **{Voice}** voice ({VoiceDescription}).

No configuration is required, just install and load the addon.

## Only one voice pack at a time

Only one BigWigs voice pack can be enabled at once, BigWigs_Voice included.

## Requirements

BigWigs.

{PacksTable}

## Voices

Wavenet_E (female), Neural2_C (female) and Studio_Q (male). Samples are on the [GitHub page](https://github.com/KogasaPls/WoWVoxPacks#voices). Install as many of them as you like, but enable only one.

## Source

Generated from Google Cloud Text-to-Speech by [WoWVoxPacks](https://github.com/KogasaPls/WoWVoxPacks), Apache-2.0. A mispronounced ability is worth an issue there.
