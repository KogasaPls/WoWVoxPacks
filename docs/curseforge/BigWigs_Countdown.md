# BigWigs Countdown: WoWVoxPacks ({Voice})

A TTS countdown voice for BigWigs. It adds **WoWVoxPacks: {Voice}** ({VoiceDescription}) to the countdown voice list.

## Turn it on

Nothing changes until you select it. In the BigWigs options, set **Countdown > Countdown voice** to `WoWVoxPacks: {Voice}`. BigWigs keeps this per profile.

## World of Warcraft: Forever

A separate World of Warcraft: Forever file is available from this project. It has the same countdown voice as the retail file, built for the Forever client.

## Requirements

BigWigs.

## Voices

Wavenet_E (en_US female), Neural2_C (en_US female) and Studio_Q (en_US male). Samples are on the [GitHub page](https://github.com/KogasaPls/WoWVoxPacks#voices). Install as many of them as you like; each is its own entry in the dropdown, so different abilities can count down in different voices.
